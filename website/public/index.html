无需 API Key，也不产生付费 API 调用。需要支持 WebGPU 的浏览器和足够 GPU/共享内存（官方四位量化估算约 2–2.7 GB，另需浏览器开销）。首次下载较大，流量、磁盘、电量由你的设备承担；公开模型文件来自 Hugging Face / MLC，不发送日志。模型文件可被浏览器缓存，日志和问题不持久保存。

免费模型只审阅前 6 个事件及问题前 500 字符；规则仍完整扫描所有采样。三项工具由程序固定读取，模型选择证据后由程序重建和核验数值，不保证电池根因诊断。模型失败会明确回退到本地规则，不会自动转用付费模型。

仅本次调用 · BYOK

模型调用会使用你本次提供的 Key，并可能在你的 API 账户计费；本站没有作者或共享 Key。Key 经 HTTPS 传至本站服务，仅用于本次请求，提交后立即从输入框清空，失败时需重新填写。Agent 模式还会将必要日志证据发送至 OpenAI。不要把 Key 放入日志或问题中。
